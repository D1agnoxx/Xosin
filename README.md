# ⚡ XOSIN

**XOSIN — eXtreme Operating System Interface Nexus**
Настольное приложение для Windows, которое объединяет управление системой, мониторинг, очистку, работу с пользователями и ИИ-ассистента в одном тёмном интерфейсе.

## 📖 О проекте
XOSIN — это «швейцарский нож» для Windows, написанный на Python + CustomTkinter.  
Вместо десятка отдельных утилит и консолей — одно приложение с современным UI, 5 темами и живыми графиками.

Расшифровка названия:
- **X** — eXtreme
- **O** — Operating
- **S** — System
- **I** — Interface
- **N** — Nexus

## ✨ Возможности
### 🏠 Дашборд
- Карточки CPU / RAM / Disk / ядер
- Live-графики загрузки CPU и RAM
- 8 быстрых действий с компактными подписями

### 🖥️ Системные инструменты
- Диспетчер задач, список процессов
- 5 цветовых тем (Midnight, Neon, Cyberpunk, Ocean, Sunset)

### ⚙️ Утилиты
- Очистка: корзина, temp, DNS, эскизы
- Быстрый доступ к системным папкам
- Реестр, службы, планировщик, event viewer, msconfig
- PowerShell и CMD с правами админа

### 🛡️ Безопасность
- Быстрая и полная проверка
- Проверка автозагрузки и процессов
- Запуск Windows Defender

### 🔑 Активатор Windows
- Windows 7 / 8 / 8.1 / 10 / 11

### 💤 Питание
- Сон, гибернация, перезагрузка, выключение с таймером

### 🌐 Сеть
- Инфо о сети, ping, tracert, netstat, arp, сброс сети

### 📊 Мониторинг
- Большие live-графики CPU и RAM
- Частота процессора

### 👤 Пользователи (от админа)
- Создание / удаление / сброс пароля
- Выдача и снятие прав администратора
- Включение / отключение аккаунтов

### 🤖 Чат с ИИ
- Интеграция с `ai_chat.py`
- Быстрые промпты
- Экспорт в TXT / JSON / MD
- Копирование и очистка истории
